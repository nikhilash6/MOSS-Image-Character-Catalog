# MOSS-Image キャラクターカタログ

**公開準備中・仮の案内です。**

MOSS-Imageで生成したキャラクター画像とプロンプトを、手元で検索・閲覧するためのカタログです。Krea2キャラクターカタログの利用方法を参考に、MOSS-Imageの画像を別コレクションとして整理しています。

この説明書の下書きには、アプリ本体・画像一式・配布パッケージを含みません。連続生成と梱包確認が済んだ段階で、公開範囲・収録数・起動手順を確定します。公開日は未定です。

## 内容

ローカル版には、キャラクター画像の検索・絞り込み、コピー用プロンプトと保存ワークフローの確認、画像の追加・編集機能があります。登録画像が20枚以下の作品は「その他の作品」にまとめ、展開すると元の作品名で選択できます。

別途導入したAnimaDexの参照画像との比較は、人による確認を補助する任意機能です。参照画像が見つかることや生成画像が似ていることだけで、キャラクター再現の合格とはしません。スタイル欄は後から整備する予定です。

## 生成画像について

現在のコレクションは、MOSS-Image-SFTのINT8 ConvRot版と、時間短縮用の8-step LoRAを用いて生成しています。途中で生成条件を変更しているため、個々の画像の実際の設定は保存ワークフローで確認します。特定の構成での利用例であり、条件を統一した性能比較や、学習済みキャラクターの完全な一覧ではありません。

キャラクター名・作品名・利用可能な外見タグは、ユーザー提供のAnima向け一覧を元にしています。タグや名前がMOSS-Imageで正しく認識される保証はありません。人物の取り違えや不完全な生成結果が含まれる可能性があり、人による確認が必要です。
