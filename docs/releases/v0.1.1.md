# v0.1.1 — Source-count ordering / 作品内のカウント順

## 日本語

- Copyright件数順で、作品内を元CSVのカウント降順に変更。作品間の登録枚数順、その他を末尾に置く扱い、名前順・生成順は維持。
- ローカル版のキャラクター33,937枚に元の生成計画と照合したカウントを付与。画像・プロンプト・ユーザー判定は変更しません。同数は名前・キー順、カウントのない追加画像は同一作品内の末尾。
- デモも同じ並べ替えに対応。デモは引き続き96キャラクター＋24スタイルのみ。デモの作品別件数は抜粋分です。
- キャラクター33,937枚＋スタイル221枚、合計34,158枚はv0.1.0と同じ画像です。未選別で、誤認・画風不一致を含みます。
- 日英READMEに、既報のWindows Python 3.13.12/Pillow 12.3.0の限定確認と、Codex Cloudで報告されたDebian 13/Python 3.10〜3.14の操作確認・未確認範囲を同梱。
- 元カタログ・v0.1.0 ZIPを保持。Release ZIPには個人設定・お気に入り・非表示・判定状態・参照ライブラリー・ログを含めません。

検証：全キャラクターのカウント照合、ポケモン全1,832画像の降順、同数・未取得値・作品グループ・その他末尾・名前順・生成順・スタイル順の回帰確認、ローカル実画面。新ZIPは全エントリーのCRC/SHA256と全34,158画像のカタログSHA256を検証して公開します。過去のPython互換性確認の範囲はREADMEを参照してください。今回その全環境を再テストしたものではありません。

## English

- Copyright (most first) now sorts character images inside each work by the recorded source CSV count, descending. Work-size ordering, Other last, name order and generation orders are retained.
- Source counts for all 33,937 local character images were matched to their original generation plans. Equal counts use name/key ties; newly added images without counts follow counted images within their work. Source counts are historical reference values, not live popularity data.
- The demo uses the same comparator and retains its 96-character/24-style boundary. Its work counts refer only to those samples.
- The 34,158 images (33,937 characters + 221 styles) are unchanged from v0.1.0 and remain uncurated.
- The package includes updated bilingual README documentation of the previously performed Windows and reported Codex Cloud compatibility checks, with their limitations; those entire environment matrices were not rerun for this patch.
- The original catalog and v0.1.0 archive are preserved. Personal settings, favorites, hidden/review state, references and runtime logs remain excluded.

Validation: all character count mappings; descending order for all 1,832 Pokemon images; tie/missing-count behavior; work grouping, Other last, name/generation/style ordering; local browser check. The published ZIP is checked against per-file CRC/SHA256 and all 34,158 catalog image hashes.
